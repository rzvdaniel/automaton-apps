# AGENTS.md

This repository holds example and catalog apps for [Automaton](https://automaton.monster). Each app is one folder with its own `automaton.json`, source and tests; there is no shared build.

- `games/`, `maintenance/`, `utilities/`: one folder per app.
- `design/automaton-app-ui/`: the UI kit every app with a page is built from.
- `tools/`: the catalog generator and CI checks. `catalog.json` is generated by CI; never edit it.
- `catalog-apps.json`: lists the apps in the catalog (category and oldest server version).

**Before building or changing any app UI, read [`.agents/skills/automaton-app-design/SKILL.md`](.agents/skills/automaton-app-design/SKILL.md).**

## Add an app

1. Create `<category>/<app>/` with `automaton.json` (a `name` and `summary` are required), source, tests and a `README.md`. Copy the shape of `maintenance/website-monitor`.
2. If it has a page, vendor the UI kit into its `ui/` folder (see the skill).
3. Add the folder to `catalog-apps.json` and the app to the table in `README.md`.
4. Add a `.github/workflows/<app>-tests.yml` that runs the app's tests.

## CI

`Catalog` runs the tool tests, `python tools/check_vendored_ui.py` (a copy of the kit that differs from `design/automaton-app-ui/` fails) and `python tools/generate_catalog.py --validate`. Each app has its own tests workflow. Run the same commands locally before opening a pull request.

Documentation: <https://automaton.monster/docs/apps-repository>
