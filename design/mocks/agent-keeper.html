This machine has an Automaton Runner but is not a GitHub agent machine yet. Set up installs Claude Code, gh, git, Docker and the build tools, registers the machine as a self-hosted runner with the agent label and starts it as a service. It takes about 5 minutes.

  1. Host access is on for this server done
  2. An administrator approved runner:host-exec for runner-01 done
  3. In GitHub open rzvdaniel/automaton, Settings, Actions, Runners, New self-hosted runner, and copy the registration token. It is valid for one hour.
  4. Paste it below and press Set up.
